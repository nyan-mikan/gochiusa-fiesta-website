# 角色列表直接添加

角色库选择列表后，在成员上方显示列表名称、人数和“添加角色”。点击后搜索中文名、日文名或别名，勾选多个已有角色，再点击“添加已选”。搜索切换保留已勾选角色，取消不修改列表；创建新列表后直接打开选择入口。原有批量新建角色、成员移除和排序继续保留。

候选包含当前活动可用的内置角色与自定义角色。已在列表中的角色、已归档角色及取消的旁白不作为新候选；隐藏角色注明状态，仍可由管理员加入。原有成员顺序不变，新选择依次追加，最多 300 位。手机通过点击完成选择与添加，不需要 Enter。

选择入口冻结当前活动、列表与成员版本。保存沿用模块权限、操作编号和乐观锁；网络重试复用同一请求编号，多人编辑只有一个成功。发生冲突时保留选择，禁止继续提交旧资料；用户点击“刷新列表”后，保留尚未加入且仍可用的选择，核对后再次添加，不能覆盖其他人的成员和顺序。若列表已归档则不允许继续添加。后端在同一事务校验成员作用域和可用状态，拒绝新加入其他活动、未知、已归档或取消的角色，但不丢弃列表已有的归档成员。

无数据库迁移，不修改角色身份或历史台词。实际本地接口与浏览器回归分别在 `scripts/character-list-checks.mjs`、`scripts/character-list-browser-checks.mjs`，接入现有集成及 Chromium 验证入口。

成员上移、下移、移除及归档共用保存等待状态，保存后读回当前顺序和版本才允许继续操作。首位不能上移，末位不能下移；快速重复点击不会发出同版本的多个请求。若他人已修改列表，拒绝覆盖并暂停该列表操作，点击标题旁“刷新列表”核对后再继续。读回失败时也暂停列表操作，避免使用过期快照。手机直接点选箭头，不需要 Enter。
