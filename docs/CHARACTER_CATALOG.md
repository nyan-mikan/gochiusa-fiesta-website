# 内置角色目录与证据边界

初始化目录含 35 个作品角色条目，以及独立的辅助发言身份“旁白”。覆盖七位主要角色、常见家人、动物、学校同学和漫画新增角色；不宣称已经穷尽全部漫画卷数、无名路人和后续新角色。稳定 ID 不使用显示名，别名不会创建重复身份。

16 个动画官网简介条目依据 [官方角色页](https://gochiusa.com/chara/)：心爱、智乃、理世、千夜、纱路、麻耶、小惠、青山、凛、萌香、隆宏、提比、心爱母亲、理世父亲、千夜祖母、狩手结良。sources 标记 official-profile。中文译名是显示名，日文名与昵称保存在别名表；未命名家人使用关系称谓，不编造姓名。

冬优依据[官方配音漫画公告](https://gochiusa.com/bloom/news/n01910000.html)；夏明/映月依据[十周年官方资料](https://gochiusa.com/10th/)。sources 标记 official-announcement。公告可证明角色出现，完整姓氏和中文译名仍需结合原作维护；“夏目”作为夏明别名，不分裂成另一角色。

其他 16 个补充条目（智乃母亲、豆馅、野雁、小惠母亲、心爱父亲和两位兄长、千夜母亲、纱路母亲及七位同学）来自[作品角色索引](https://zh.wikipedia.org/wiki/請問您今天要來點兔子嗎？)的发现资料，sources 明确标记 supplementary-needs-primary-check，并在网页显示待官方资料核对。不可把这些补充来源描述成官方已核实全集。提比/智乃爷爷通过同一身份别名处理。

更新目录时保留 stable_key 和 ID，只维护证据或显示资料；归档自定义角色，不删除已有台词引用。本活动显示名、隐藏和收藏单独存入 event_character_overrides；正式定稿使用冻结快照内的角色显示名。
