# 主持稿角色性格审核

公开主持的语言得体与角色性格分别检查。语法正确的台词也可能粗俗或明显偏离发言角色；审核只给建议，不自动改稿或阻止保存、定稿。警告仍用黄色三角形加入系统消息，可以按审核标识永久忽略。

后台在 `src/worker/services/language-character.ts` 为已有内置角色提供以下编辑预设，使用角色的稳定身份匹配，不依赖活动中修改的显示名，也不把正文里被称呼的对象当成发言者。这些是用于主持稿审核的性格概括，不是限制角色全部话术或禁止角色成长。

| 角色 | 性格和语气基准 | 正常变化，不应机械警告 |
| --- | --- | --- |
| 保登心爱 | 元气、热情、亲切，爱交朋友和照顾大家，憧憬姐姐身份，偶尔冒失 | 兴奋、撒娇、逞姐姐、温柔打趣 |
| 香风智乃 | 文静、慢热、礼貌克制，认真照顾咖啡店，会冷静吐槽 | 简短回应、吐槽、害羞、闹别扭、表达亲近或偶尔活泼 |
| 天天座理世 | 认真可靠、有责任感、直率干练，内心喜欢可爱事物 | 军事用语、较强语气、害羞和慌张 |
| 宇治松千夜 | 温柔从容、和风气质，爱诗意命名，会一本正经地开玩笑 | 腹黑玩笑、调侃和逗趣，不能直接等同于恶意 |
| 桐间纱路 | 努力认真、勤俭，通常礼貌，也容易害羞、紧张或倔强 | 激动吐槽、情绪变化，对理世的憧憬 |
| 条河麻耶 | 活泼开朗、直爽、爱运动，喜欢玩闹和尝试 | 随意爽快的发言、较大声、淘气和直接调侃 |
| 奈津惠 | 温柔天真、容易害羞，有时天然，重视朋友并憧憬成熟 | 偶尔坚定、兴奋、勇敢或尝试主动 |
| 提比 | 成熟长辈的关怀和幽默，关注智乃与咖啡店，会吐槽或困扰 | 长辈式提醒、玩笑，不只套用普通萌兔话术 |
| 保登萌香（摩卡） | 温暖亲切、包容，姐姐气质强，关爱心爱和周围的人 | 姐姐式玩笑、天然、兴奋、逗弄妹妹 |
| 青山翠 | 温和悠然，有作家的观察力和文艺气质，有时天然或调皮 | 联想、寻找灵感、温柔打趣和轻松吐槽 |

只有明显违背核心性格的表达才警告，例如智乃狂妄地宣称所有人都低她一等，或心爱恶意羞辱、排斥朋友。少用敬语、普通口语、友善吐槽或正常情绪变化不应单独触发。舞台提示可解释情境与表演；公开主持中的明显粗口和辱骂仍检查。

严重 CP 倾向也独立检查，不要求同时违背角色性格：明确强行确立恋爱、情侣或婚恋关系，强烈排他占有，或持续/强烈的恋爱和性暧昧暗示，提示具体原文及回到友情/姐妹互动的修改建议。判断不区分异性或同性配对。例：“心爱，从今天起我们就是恋人了，你只能喜欢我，不许再对别人那么好。”应提示关系强加和排他占有。CB（友情、搭档、组合关系）允许；互相信任、协作、共同成长及朋友/姐妹间的亲近不应被当成 CP。“最喜欢姐姐了”“有你陪着真好”“我们是最好的朋友”“今天也一起加油吧，我最信任的搭档”、普通关心、姐妹撒娇及单次轻度玩笑不因亲近词语单独警告。明确引用、否定与舞台情境参与判断，不把“不要把我们写成恋人”当成关系确立；仅标注扮演或玩笑也不能自动免除强烈的 CP 表达。自定义或未指定发言者仍可按文本证据检查严重 CP 倾向，不能凭空推断配对。

单人按所选角色；分段按各自片段的角色；合说分别检查各发言者。未预设的自定义角色（包括与内置角色同名的自定义角色）、未指定角色、注释和小标题不推测性格。预设角色的可用性仍由角色管理决定。

登记审核时把性格和发言片段关系冻结到该标识，等待期间继续编辑不会改变旧任务的发言者。更改角色后使用新的台词版本和审核标识；角色选择框离开焦点也可触发，分段发言设置在离开发言区域时触发。刷新复用结果，不重新调用；此前已经完成的空反馈不因规则升级而改写或重发，需要修改台词或角色产生新版本。

性格判断仍依赖所配置模型的理解，只对明确冲突给建议，不能保证穷尽所有偏离。模型协议、配置及失败处理见 [SCRIPT_LANGUAGE_REVIEW.md](SCRIPT_LANGUAGE_REVIEW.md)。
