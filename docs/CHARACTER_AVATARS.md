# 角色头像

角色库卡片及列表添加窗口共用头像显示。没有图片或图片读取失败时保留文字头像，名称与原有搜索、筛选、排序仍可用。

创建自定义角色时，填写名字后，每个名字下都有独立的“头像（可选）”入口。支持选择文件和拖放 PNG、JPEG、WebP，原图最大 2 MiB。浏览器先解码、裁成 384 × 384 方形并压缩，处理期间禁止提交；头像与角色一起保存。未选择图片时照常创建，批量创建不同角色可以分别选填。

角色设置可替换或移除自定义角色头像；不修改头像时保留原图，取消不保存。遇到版本冲突，保留未保存的头像和字段，要求明确刷新角色资料、核对后保存，不自动覆盖其他人的修改。

图片复用现有私有 R2。`character_sources` 以 `uploaded-avatar` 标记记录本站图片来源，`avatar_url` 从该来源派生，未增加数据库列或表。角色创建/更新、图片来源及版本在同一 D1 事务提交；失败时清理新文件，成功替换/移除后清理旧文件。R2 对象由活动、角色和内容散列确定，跨活动不会共用可覆盖的文件路径。已有模块权限、幂等、乐观锁和协作队列保持有效。

后端复核编码、256 KiB 大小上限、格式签名和最多 512 × 512 的图片尺寸，拒绝 SVG、伪造 MIME 与无效数据。图片读取仅允许拥有角色、主持稿或节目编排权限的登录管理员，验证来源与活动/角色绑定并禁用缓存，不开放作品上传桶，不接受任意外站图片地址。

## 公式照

已核实并注册 19 张官网原图，覆盖目前可用的心爱、智乃、理世、千夜、纱路、麻耶、小惠、提比、冬优、夏明与映月，以及 8 位有独立官网角色页的历史归档角色。归档状态不变；其他未找到可靠独立图片的归档角色继续使用文字头像。

10 位女孩使用官网 [Koi 先生 2023 年情人节头像配布](https://gochiusa.com/special/v2023.html)的方形图片，该页面提供带角色名的下载链接，明确区分冬优、夏明和映月。提比及青山翠、真手凛、萌香、隆宏、心爱的母亲、理世的父亲、千夜的祖母、结良使用各自官网角色页的头像。图片保持原始字节及原图署名，不使用生成图或未经核实的替代图。

原图位于 `public/images/characters/`，文件名含内容散列；`src/shared/character-avatar.ts` 以固定角色 ID 绑定本站图片。核实日期、来源页、原图 URL、完整 SHA-256、尺寸、体积与显示位置见 [character-portraits.json](character-portraits.json)。图片随网站构建部署，浏览器不请求外站；不需要额外服务、R2 写入或数据库迁移。

2026-10-07 用户应用官网域名许可后，`gochiusa.com` 与 `www.gochiusa.com` 实际请求均返回 200，原网络阻塞已解除。已沿用环境代理及 TLS 下载原图，无需再次添加域名。

验证入口：`scripts/character-avatar-checks.mjs` 接入 HTTP 集成，验证所有公式照的身份、散列、尺寸、PNG MIME 及构建后实际图片字节，避免遗漏图片时被单页 HTML 回退掩盖。`scripts/character-avatar-browser-checks.mjs` 接入完整 Chromium 回归，验证全部可用公式照解码、卡片/列表窗口、刷新、失败回退及 320/390/1440px 布局。自定义上传仍使用本地合成 PNG 与合成账号，不使用生产上传或真实账号。
