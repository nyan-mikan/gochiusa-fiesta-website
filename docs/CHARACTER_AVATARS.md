# 角色头像

角色库卡片及列表添加窗口共用头像显示。没有图片或图片读取失败时保留文字头像，名称与原有搜索、筛选、排序仍可用。

创建自定义角色时，填写名字后，每个名字下都有独立的“头像（可选）”入口。支持选择文件和拖放 PNG、JPEG、WebP，原图最大 2 MiB。浏览器先解码、裁成 384 × 384 方形并压缩，处理期间禁止提交；头像与角色一起保存。未选择图片时照常创建，批量创建不同角色可以分别选填。

角色设置可替换或移除自定义角色头像；不修改头像时保留原图，取消不保存。遇到版本冲突，保留未保存的头像和字段，要求明确刷新角色资料、核对后保存，不自动覆盖其他人的修改。

图片复用现有私有 R2。`character_sources` 以 `uploaded-avatar` 标记记录本站图片来源，`avatar_url` 从该来源派生，未增加数据库列或表。角色创建/更新、图片来源及版本在同一 D1 事务提交；失败时清理新文件，成功替换/移除后清理旧文件。R2 对象由活动、角色和内容散列确定，跨活动不会共用可覆盖的文件路径。已有模块权限、幂等、乐观锁和协作队列保持有效。

后端复核编码、256 KiB 大小上限、格式签名和最多 512 × 512 的图片尺寸，拒绝 SVG、伪造 MIME 与无效数据。图片读取仅允许拥有角色、主持稿或节目编排权限的登录管理员，验证来源与活动/角色绑定并禁用缓存，不开放作品上传桶，不接受任意外站图片地址。
